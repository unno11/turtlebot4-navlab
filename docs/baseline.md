# 官方基线结果

本页是 TurtleBot 4 NavLab 在 warehouse 场景下的官方基线。后续任何改动（行为树、感知、障碍物、DDS）都应与这里的数字对照。

[返回首页](../README.md) · [目标集](goal_set.md) · [实验记录](experiment_logging.md) · [结果目录](../results/README.md)

## 场景与条件

| 项 | 值 |
| --- | --- |
| 世界 | Gazebo `warehouse` |
| 定位 | AMCL，起点固定 `S0 = map (0, 0, 0)`，参数见 `config/localization.yaml` |
| 导航 | Nav2 + `turtlebot4_navigation` 默认参数，未做修改 |
| 目标集 | 8 个，分类与判据见 [目标集与难度定义](goal_set.md) |
| 每次试验 | 整套仿真重启，机器人重新出生、AMCL 重新初始化 |
| 执行方式 | `scripts/run_batch.sh`，每个目标 3 次，共 24 次 |

## 指标口径

- **导航耗时**取自 Nav2 反馈的仿真时间，与墙钟无关。墙钟耗时受宿主机性能影响（RTF 在 0.22–0.30 之间时，墙钟约为仿真时间的 3–5 倍），跨机器不可比，因此不进本表，只保留在本地记录的 `duration_wall_s` 中。
- **恢复次数**是 Nav2 自身的计数，反映该路线上触发恢复行为的次数。
- **碰撞次数不采集**：自动记录没有可靠的碰撞来源，`collisions` 字段保持空值。空值表示未知，不等于零。
- 本页数字由 `scripts/summarize_results.py` 从本地 `results/runs/*/run.json` 生成，不做手工填写。

## 复跑

```bash
cd ~/turtlebot4_ws/src/turtlebot4-navlab
TRIALS=3 ./scripts/run_batch.sh
```

跑完后重新生成上表：

```bash
/usr/bin/python3 scripts/summarize_results.py
```

## 边界

- 本基线只覆盖 warehouse 场景与固定起点 S0。更换世界、起点或 Nav2 参数后必须重新测量，不能沿用。
- 本地记录共 27 条，其中 24 条形成导航结果计入上表；其余 3 条未形成导航结果，不参与统计，原因记录在各自的 `run.json` 中，分类规则见 [实验记录](experiment_logging.md)。
